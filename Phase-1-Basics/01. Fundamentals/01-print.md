# print()

#Function:

#The print()-function is a simple and crucial function in python, which allows you to print data.
#This includes text, numbers, variables...

#Syntax & Execution:
 
#1. Text has to be defined through single quotes '' or double quotes "" ( 1 )
#2. Adding values with + ( 2 )
#3. Empty place with ' '  or " " (  3 )
#4. Place holder ( 4 )
#5. Print "" or '' with triple quotes

#Examples 

#(1)

print("Hello World")

#Prints Hello World

#( 2 )

print("Hello"+"World")

#Both texts get added to Hello World.
#! Values need to have the same type : More of that in 05-types.md

#( 3 )

print("Hello" + " " + "World"

#Prints Hello World
#The quotes " " made an empty place between

#( 4 )

print("Hello")
print()
print("What's going on")

#Prints:
#Hello 
#( The empty print() holds one line. Without it they would'nt have an empty line in between.
#What's going on 

#( 5 )

print(""" I like "pizza"""")

#Prints I like "pizza"

#With triple quotes you can insert quotes up to your liking
